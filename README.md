# 🎲 ROLL & REVEL — The Ritual of Chance

**ROLL & REVEL** is an interactive dice roller that turns a simple JavaScript exercise into an elegant, playful experience. Featuring a rich burgundy palette, ivory dice, subtle animations, and a roll history, the application combines functionality with a distinctive visual identity.

## ✨ Features

- **Roll 1–6 dice:** choose how many dice to roll.
- **Random results:** generate values from 1 to 6 for each die.
- **Automatic total:** calculate the sum of all dice in each roll.
- **Animated dice:** enjoy a custom CSS rolling animation.
- **Roll history:** review previous rolls and their totals.
- **Clear history:** reset the recorded rolls when needed.
- **Responsive layout:** adapt the interface to desktop and mobile screens.
- **Accessible interactions:** use semantic HTML, keyboard focus indicators, descriptive labels, and screen-reader status announcements.
- **CSS-generated dice:** create dice faces using HTML and CSS instead of external image assets.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- CSS Grid and Flexbox
- CSS animations and custom properties
- Google Fonts

No JavaScript framework, package installation, or build process is required.

## 🎨 Design Concept

The visual direction, **The Ritual of Chance**, takes inspiration from elegant tabletop games and collectible objects.

The interface combines:

- **Deep burgundy** for a dramatic atmosphere.
- **Warm ivory** for the dice and readable surfaces.
- **Soft gold** for highlights and interactive elements.
- **Playfair Display** for expressive editorial headings.
- **DM Sans** for clear, modern interface text.

The dice are created entirely with HTML and CSS, including their pips, shadows, depth, and rolling animation.

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Cameloasa/DiceRollerProgram.git
   ```

2. Open the project folder:

   ```bash
   cd DiceRollerProgram
   ```

3. Open `index.html` in your browser.

You can also open the project folder in Visual Studio Code and use the Live Server extension for local development.

## 🧠 Learning Outcomes

This project provides practical experience with:

- Generating random integers using `Math.random()` and `Math.floor()`.
- Working with arrays and array methods such as `map()`, `reduce()`, and `forEach()`.
- Creating and updating DOM elements dynamically.
- Handling click events and application state.
- Using `setTimeout()` to coordinate interface updates with animations.
- Building responsive layouts with CSS Grid and Flexbox.
- Creating visual effects with CSS animations and transitions.
- Improving accessibility with semantic markup and ARIA attributes.

## ♿ Accessibility

The application includes visible keyboard focus styles, accessible button labels, descriptive dice labels, and a live status region for announcing results.

The stylesheet also respects the user's reduced-motion preference.
